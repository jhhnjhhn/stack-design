# Frontend

First decide SPA, SSR, SSG, or progressively enhanced HTML. Use Vite with the team's SPA framework for authenticated tools without SEO. Consider Next.js/Nuxt/SvelteKit when SSR, SSG, public content, or integrated full-stack delivery creates value. Consider Astro for content-heavy sites and HTMX/vanilla for small server-rendered interactions. Compare team skill, component needs, accessibility, deployment runtime, caching boundaries, and AI-maintainability.
