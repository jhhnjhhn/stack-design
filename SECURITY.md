# Security

Stack Design is a local knowledge and validation package. It does not require credentials, a network service, or a model API key.

Report suspected vulnerabilities privately through GitHub's security-advisory feature for this repository. Do not include secrets or proprietary project requirements in a public issue.

Repository detection reads supported manifests only. It deliberately ignores `.env` files, dependency directories, build output, and version-control metadata. Treat generated recommendations as engineering input, not security, legal, medical, or regulatory certification.
